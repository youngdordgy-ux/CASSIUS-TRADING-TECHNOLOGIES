
# CASSIUS TRADING TECHNOLOGIES

## Project Overview
CASSIUS is a financial technology software project focused on intelligent market analysis and MetaTrader 5 integration.

## Main Products

1. CASSIUS Market Analyzer
2. CASSIUS MT5 Expert Advisor
3. CASSIUS Customer Website
4. CASSIUS Subscription Management

## Supported Markets
- Forex
- Stocks
- Indices
- Commodities

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express
- Database: PostgreSQL
- Trading integration: MQL5
- Platform: MetaTrader 5

## Analyzer Features

- EMA trend analysis
- RSI momentum analysis
- MACD analysis
- ATR volatility analysis
- BUY, SELL and WAIT signals
- Indicator agreement scoring
- Historical analysis reports

## Development Phases

Version 1.0: Market Analyzer
Version 1.1: Advanced Analysis
Version 1.2: MT5 Demo Integration
Version 1.3: Performance Reporting
Version 2.0: Customer Website

## Safety and Testing

Initial development uses simulated trading.
No real-money orders are submitted by the initial software.
