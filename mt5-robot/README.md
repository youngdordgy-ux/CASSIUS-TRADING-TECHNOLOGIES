
# CASSIUS MT5 Expert Advisor

This module contains the MetaTrader 5 integration.

## Initial capabilities

- Read market prices.
- Read technical indicators.
- Identify market trends.
- Generate BUY, SELL and WAIT analysis.
- Display indicator agreement scores.
- Record analysis results.

## Position monitoring

The development roadmap includes simulated:
- Position monitoring.
- Stop-loss calculations.
- Take-profit calculations.
- Performance reporting.

## Restrictions

Initial versions must not submit real-money trading orders.

All testing takes place in an isolated demo environment.
