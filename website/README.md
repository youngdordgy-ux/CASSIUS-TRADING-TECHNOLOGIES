
# CASSIUS TRADING TECHNOLOGIES WEBSITE

## Purpose
The official customer website for CASSIUS Trading Technologies.

## Main pages

- Home
- Market Analyzer
- Customer Dashboard
- Registration
- Login
- Pricing
- Documentation
- Frequently Asked Questions

## Business Model

Free Basic:
- Basic educational market analysis.
- Limited analysis history.

Premium:
- Advanced analytical features.
- Extended historical reports.
- Additional dashboard features.

## Design

- Default background: Pure black
- Primary accent: Royal blue
- Secondary colour: White
- Responsive mobile-first layout

## Security

Customer authentication and subscription management will be handled by the backend.
