
# CASSIUS Backend

The backend powers the CASSIUS Trading Technologies platform.

## Technology
- Node.js
- Express.js
- PostgreSQL

## Responsibilities

1. Customer authentication.
2. User account management.
3. Market analysis API.
4. Analysis history.
5. Subscription management.
6. Software licensing.
7. Website communication.

## Security

- Secure password handling.
- Input validation.
- Protected API endpoints.
- Environment-based configuration.
- No storage of broker passwords.

## Initial Mode

Educational analysis and simulated trading only.
