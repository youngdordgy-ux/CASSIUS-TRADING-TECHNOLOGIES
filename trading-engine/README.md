
# CASSIUS Market Analysis Engine

This module is responsible for analyzing financial market information.

## Initial indicators

- EMA (20 and 50)
- RSI (14)
- MACD (12, 26, 9)
- ATR (14)

## Analysis outputs

- BUY
- SELL
- WAIT

## Signal scoring

The engine measures agreement between selected technical indicators.

The agreement score is not a probability of profit.

## Initial development mode

Educational analysis and simulated trading only.

## Future improvements

- Multiple timeframe analysis
- Historical market-data analysis
- Volatility analysis
- Performance reporting
- MT5 integration
